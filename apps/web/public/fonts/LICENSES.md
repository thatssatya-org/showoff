# Self-hosted web fonts

These files are Latin WOFF2 subsets sourced from Fontsource 5.3.0.

- Recursive (`@fontsource-variable/recursive` 5.3.0) — SIL Open Font License 1.1
- IBM Plex Sans (`@fontsource/ibm-plex-sans` 5.3.0) — SIL Open Font License 1.1
- IBM Plex Mono (`@fontsource/ibm-plex-mono` 5.3.0) — SIL Open Font License 1.1

The source package licenses are available from Fontsource and the respective font projects. Font files are served locally; the page makes no runtime font request.
